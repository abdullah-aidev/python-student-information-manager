# Student Information Manager 🐍

A beginner-friendly Python project that collects student information and stores it in a dictionary.

## Features
- Takes student name as input.
- Takes student age.
- Takes favourite subject.
- Stores information in a Python dictionary.
- Displays student information.
- Checks age eligibility using if/else statements.

## Concepts Used
- Python Variables
- User Input
- Integer Conversion
- Dictionaries
- Print Statements
- If/Else Conditions

## How to Run

```bash
python main.py
```
